# Sistema de Gerenciamento de Campeonato

Projeto acadêmico desenvolvido em linguagem C durante a graduação em Engenharia de Software.

## Sobre o projeto

O sistema tem como objetivo gerenciar informações de um campeonato, permitindo organizar participantes, registrar resultados e realizar operações relacionadas à classificação e pontuação.

## Tecnologias utilizadas

- Linguagem C
- Dev-C++

## Conceitos de programação aplicados

- Estruturas de repetição (`for`, `while`)
- Estruturas condicionais (`if` e `else`)
- Vetores e matrizes
- Funções
- Variáveis
- Operações matemáticas

## Arquivo principal

- Arquivo-fonte do sistema em linguagem C (`.c`).

## Objetivo

Aplicar conhecimentos de lógica de programação e desenvolver habilidades na linguagem C por meio da criação de um sistema de gerenciamento de campeonato.
